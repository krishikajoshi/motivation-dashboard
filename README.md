# 🌟 Motivation Dashboard

A simple and interactive React-based web application that displays random motivational quotes and allows users to like and save them for later.

---

## 🚀 Live Demo

https://motivation-dashboard-six.vercel.app

---

## 📌 Features

* 🔄 Fetch random quotes from an API
* 🧠 Display quote along with author
* ❤️ Like and save your favorite quotes
* 💾 Data persists using localStorage
* ⚡ Fast and responsive UI

---

## 🛠️ Tech Stack

* React.js
* JavaScript (ES6)
* CSS
* DummyJSON API

---

## 📂 Project Structure

* `src/` → Main application code
* `App.js` → Core logic and UI
* `App.css` → Styling
* `index.js` → Entry point

---

## ▶️ How to Run Locally

```bash
npm install
npm start
```

---

## 💡 How It Works

* Quotes are fetched from an API using `fetch`
* Data is stored using React `useState`
* `useEffect` is used to load data on initial render
* Liked quotes are saved in localStorage
